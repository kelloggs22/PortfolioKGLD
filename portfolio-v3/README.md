# Portfolio — Kelly Lee da Silva

[![My Skills](https://skillicons.dev/icons?i=nextjs,react,ts,tailwind,threejs)](https://skillicons.dev)

Código fuente de mi portfolio personal, desplegado en **[portfolio-kgld.vercel.app](https://portfolio-kgld.vercel.app)**.

## 🚀 Descripción
Sitio personal donde muestro mis proyectos full-stack (app de reservas, app y panel de seguimiento de pacientes) y mi stack técnico, pensado para reclutadores y equipos de desarrollo.

## 🛠 Tecnologías utilizadas

- **Framework:** [Next.js](https://nextjs.org/)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
- **UI:** [React](https://react.dev/) + [Tailwind CSS](https://tailwindcss.com/)
- **3D/Animaciones:** [Three.js](https://threejs.org/) (`@react-three/fiber`, `@react-three/drei`), [Motion](https://motion.dev/)

## ⚙️ Configuración e instalación

```bash
git clone https://github.com/kelloggs22/PortfolioKGLD.git
cd PortfolioKGLD/portfolio-v3
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en el navegador.

## 👩‍💻 Sobre este proyecto
Diseño y desarrollo completo del sitio: estructura, componentes, animaciones 3D con Three.js y contenido de cada proyecto mostrado.
